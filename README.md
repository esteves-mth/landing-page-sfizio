# Landing Page Sfizio
 
Landing page da marca fictícia **Sfizio** (massas italianas), desenvolvida como projeto escolar, complementar ao projeto [sfizio-massas](https://github.com/esteves-mth/sfizio-massas) — o e-commerce completo da mesma marca.
 
## Sobre o projeto
 
A atividade consistiu em pesquisar o conceito de landing page e depois desenhar e construir uma landing page para o negócio criado anteriormente, mantendo a mesma identidade visual do site principal. A página segue a estrutura básica (cabeçalho, conteúdo e rodapé), com pelo menos três rolagens e um Call to Action em destaque.
 
## Funcionalidades
 
- Página única com múltiplas seções de rolagem e Call to Action
- **Alternância de tema claro/escuro**, com JavaScript e variáveis CSS, salvando a preferência do usuário no `localStorage`
## Tecnologias
 
- HTML5 e CSS3, com variáveis de CSS para o sistema de temas
- JavaScript puro, sem bibliotecas externas
- Identidade visual consistente com o site principal (mesma tipografia customizada `XperiencePasta.ttf` e paleta de cores)
## Como visualizar
 
Basta abrir o arquivo `index.html` em qualquer navegador ou clicar no seguinte link: [landing-page-sfizio](https://esteves-mth.github.io/landing-page-sfizio/)
